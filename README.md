資產管理（gold-tracker）
單機網頁應用：用瀏覽器追蹤台股／ETF與黃金持倉，計算現值、損益、年化，並用「目標月領」規劃存股進度。資料存在本機 `localStorage`，不經自家後端。
原始碼幾乎全部在 `index.html`。完整 HTML 備份見 `index.html.txt`。
---
如何開啟
用瀏覽器直接開 `index.html`，或用本機靜態伺服（避免部分 API 被檔）：
```bash
# 例：專案資料夾下
npx --yes serve -l 8765
# 或任何靜態伺服，瀏覽 http://127.0.0.1:8765/
```
首次進入預設隱私模式（金額顯示 `\*\*\*\*`）。解除遮罩需管理密碼，預設為 `000000`（可在設定修改）。

執行流程
```
開啟頁面
  → 讀 localStorage（持倉、賣出、股價快取、設定、目標計畫）
  → updateUI() 重算並重繪
  → fetchAllPrices() 拉金價、匯率、持倉股價

核心函式：
`updateUI()`：彙總現值、成本、損益、圖表、報表、同齡對照；目標頁開啟時重算計算機
`switchView(name)`：切換總覽／目標／股票／黃金／報表
`saveAll()`：把持倉、賣出、股價寫回 `localStorage`
`renderGoalCalc()`／`renderGoalChart()`：存股目標與時間曲線
`renderPeerCompare()`：同齡儲蓄對照
`renderReport()`：期間損益報表
`renderCharts()`：總覽折線與配置圖

計算公式
符號：`num(x)` 表示無效當 0。1 張＝1000 股。1 台錢＝3.75 公克。
單位與成本
```
股數（由張）     = 數量 × 1000
黃金公克         = 台錢 ? 重量 × 3.75 : 重量

買入成本（空白） = 股數 × 成交單價
股利再投入       → 股數保留；成本與股利同額（口袋淨現金成本視為 0）
現金股利         → 股數 0、成本 0；只記股利金額

口袋淨現金成本 netHoldingCashCost：
  現金股利     = 0
  股利再投入   = max(0, 成本 − 股利)   ≈ 0
  買入         = 成本
```
現值
```
股票一筆現值     = 現價(無則用買入單價) × 股數
股票總現值 sV    = Σ 各筆現值
股票總股數       = Σ 股數

金價（台幣／公克）= (PAXG 美元／金衡盎司) ÷ 31.1035 × USD/TWD
黃金一筆現值     = 公克 × 金價（台幣／公克）
黃金總現值 gV    = Σ 各筆現值

總覽淨值 tV      = （計入則加）sV + gV
```
工費與金料
```
金料成本 goldMetalCost = 有購入金價 ? 公克 × 購入金價／公克 : 總購入成本
工費 goldLaborCost     = 總購入成本 − 公克 × 購入金價／公克
                         （缺公克或購入金價則為空）
黃金未實現（列）       = 現值 − 金料成本
```
賣出
```
賣出金額           = 使用者填的賣出金額
已實現損益         = 賣出金額 − 買入成本（FIFO 攤到的成本）
賣出報酬率         = 已實現損益 ÷ 買入成本 × 100%
```
FIFO：同標的依日期由舊到新扣股數或公克；按比例分攤成本（與股利）。不夠賣則還原快照、不入帳。
未實現與總報酬
```
股票未實現         = sV − 股票持倉淨現金成本
黃金未實現         = gV − 黃金持倉總成本
總未實現           = 計入項目的未實現加總

總報酬率 totalPerfPct（全程、非年化、不含「股利當收益加回」的獨立項）：
  分母 basis = 現有淨現金成本 + 已賣出買入成本
  分子 gain  = 現值 + 已實現損益 − 現有淨現金成本
  報酬率     = gain / basis × 100%

股票彙總列報酬     = 同上，但用該代號的 worth、netCost、realized、soldCost
```
股利再投入不算口袋本金，因此不會把「股利滾進去的成本」算進分母。
年化 XIRR
現金流：
買入：`−成本`（日期＝交易日）
現金股利：`＋股利`
再投入：淨現金 0（不列）
賣出：`＋賣出金額`
期末：今天加上目前現值（視為虛擬回收）
```
NPV(r) = Σ  amount\_i / (1+r)^t\_i
t\_i    = (日期\_i − 最早日期) / 365.25 年
```
牛頓法求 `NPV(r)=0` 的 `r`，失敗則二分搜尋。持有未滿 30 天顯示「xx%（短）」。正負現金流不齊則不計算（`--`）。
目標計算機
選代號自動帶入：持倉股數、現價、每股年配息。
每股年配息（自動）
資料：FinMind `TaiwanStockDividend`（或股利頁快取）。
```
單期現金 = CashEarningsDistribution + CashStatutorySurplus
日期     = 除息日 CashExDividendTradingDate
股票股利不計入
```
將除息日落在「今天往回 365 天」內的現金全部加總 → 近一年 DPS
若加總為 0：改用最近一個有配息的日曆年各期現金合計
可手動覆寫。四捨五入到小數第 4 位。
由月領反推與進度
```
目前月領 nowDiv      = 目前持股 × DPS ÷ 12
需存股數 targetSh    = 目標月領 × 12 ÷ DPS
需存張數             = targetSh ÷ 1000
預估本金             = targetSh × 現價
還差本金             = max(0, targetSh − 目前持股) × 現價
還差月領             = max(0, 目標月領 − nowDiv)
還差股數             = max(0, targetSh − 目前持股)
月領進度             = nowDiv / 目標月領 × 100%
```
達標模擬 `simulateGoalPath`
每月（最多 600 個月＝50 年）：
```
持股 += 每月投入 / 現價          （有填投入且現價 > 0）
每滿 12 個月：
  年度現金 = 持股 × DPS
  若「股利再投入」：持股 += 年度現金 / 現價
當 持股 × DPS / 12 ≥ 目標月領 即達標
```
假設：現價、DPS、每月投入固定；一年配一次。沒有投入且無法靠再投入增加持股 → 顯示無法估算。
不把「每月投入」回推歷史：該欄是未來假設。過去實際投入以股票頁交易為準，目標圖目前從「今天」往後畫。
同齡儲蓄對照
資料：行政院主計總處《113 年家庭收支調查》「每人年儲蓄」（程式內建常數，單位元）：
年齡	年儲蓄
未滿 30	94,242
30–34	121,318
35–39	124,164
40–44	106,182
45–54	114,230
55–64	138,754
65 以上	61,606
```
年齡           = 今年 − 出生年
同齡累積基準   = Σ（a = 22 … 年齡−1）該歲年儲蓄
你的資產       = 總覽淨值 tV + 手填銀行存款
相對基準       = 你的資產 / 同齡累積基準
差距           = 你的資產 − 同齡累積基準
```
基準＝假設自 22 歲起每年存下該年齡組平均、不含投資報酬與買房等支出。不是官方排名。
相對位置文案：≥2 倍明顯高於；≥1 高於；＜0.7 低於；其餘接近。
報表
```
期間已實現 = Σ（賣出日落在該月或該年的已實現損益）
未實現     = 目前持倉未實現（不是期間切片）
報表合計   = 期間已實現 + 目前未實現
```
當期可領股息
依持倉股數 × `pickCurrentCashDiv` 選出的每股現金：
即將除息（除息日 ≥ 今天，最早一筆）
否則待發放（發放日 ≥ 今天）
否則本年度最近一期
否則最近一期（參考）
可領金額 ＝ 持有股數 × 該期每股現金。
填權息天數
除息（或除權）前收盤價為 `beforePrice`。自除息日之後的交易日，股價首次回到 ≥ 除息前價的天數（最多查 250 日）。資料來自 FinMind 股價與股利結果列。
趨勢圖累計
依所有計入資產的交易日排序：
股票買入：累計成本 ＋＝成本（再投入／現金股利不增加口袋成本線）
現值：用目前市價 × 當時已持有股數（不是歷史還原價）
因此趨勢圖的「現值」是「用今天價格回看當時持股」，不是當時真實市值。

報酬率           → 小數兩位 + %
損益顏色         → 正數 c-gain（紅）、負數 c-drop（綠）（台股習慣）
```
